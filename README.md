## 📱 وصف التطبيق

تطبيق أندرويد احترافي لحل مكعب روبيك باستخدام **خوارزمية Kociemba** الشهيرة، مع واجهة مستخدم عربية كاملة وتصميم داكن عصري.

## 🚀 كيفية البناء

### المتطلبات
- Flutter 3.10+ مع Dart 3.0+
- Android SDK (API 21+)
- Android NDK (مضمن مع Flutter)
- Java 11+

### خطوات البناء

#### 1. تثبيت Flutter
```bash
# Linux/Mac
git clone https://github.com/flutter/flutter.git -b stable
export PATH="$PATH:`pwd`/flutter/bin"

# التحقق
flutter doctor
```

#### 2. تجهيز المشروع
```bash
cd rubik_solver_ar
flutter pub get
```

#### 3. بناء APK الإصدار
```bash
# APK موحد
flutter build apk --release

# APK منفصل لكل معمارية (أصغر حجماً)
flutter build apk --release --split-per-abi
```

#### 4. أو استخدم السكريبت الجاهز
```bash
chmod +x build_release.sh
./build_release.sh
```

## 🎮 طريقة الاستخدام

### 1. إدخال حالة المكعب
- اختر وجهاً من قائمة الوجوه الست (علوي، سفلي، أمامي، خلفي، أيمن، أيسر)
- اختر اللون من لوحة الألوان السفلية
- انقر على كل خانة في الشبكة 3×3 لتعيين لونها

### 2. التحقق من الإدخال
- كل لون يجب أن يظهر **9 مرات بالضبط**
- المركز لكل وجه ثابت ولا يمكن تغييره
- يمكن مشاهدة المعاينة الشبكية في الأعلى

### 3. حل المكعب
- اضغط على **"حل المكعب"**
- ستظهر الحركات المطلوبة خطوة بخطوة
- استخدم أزرار التنقل للمرور على كل حركة

## ⚙️ الخوارزمية: Kociemba Two-Phase

خوارزمية **Kociemba** هي من أفضل خوارزميات حل مكعب روبيك:

**المرحلة الأولى (Phase 1):** تحويل المكعب إلى المجموعة G1
- توجيه جميع الأركان والحواف بشكل صحيح
- وضع حواف الشريحة الوسطى في مواضعها

**المرحلة الثانية (Phase 2):** حل المكعب ضمن G1
- ترتيب الأركان والحواف مع القيود
- النتيجة: حل في 20 حركة أو أقل (God's Number)
